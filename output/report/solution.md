# Project 3 — Curve Interpolation

## Part 1: Natural end conditions

Let P_i denote the given data points (called x_i in the PDF). All equations
below are vector equations, applied to both coordinates.

A cubic Bezier curve is

C(t) = (1-t)^3 b0 + 3(1-t)^2 t b1 + 3(1-t)t^2 b2 + t^3 b3.

Differentiating gives

C'(t) = 3[(1-t)^2(b1-b0) + 2(1-t)t(b2-b1) + t^2(b3-b2)],

C''(t) = 6[(1-t)(b0-2b1+b2) + t(b1-2b2+b3)].

Consequently C''(0)=6(b0-2b1+b2) and C''(1)=6(b1-2b2+b3).

For the first segment, b0=P0, b1=d0, b2=(d0+d1)/2. Setting
C''(0)=0 yields 2P0-3d0+d1=0, hence

d0 = (2P0+d1)/3.

For the last segment, b1=(d_{N-1}+dN)/2, b2=dN, b3=PN.
Setting C''(1)=0 yields d_{N-1}-3dN+2PN=0, hence

dN = (d_{N-1}+2PN)/3.

For N>=4, the first row of Equation (1) is

(7/2)d1+d2 = 6P1-(3/2)d0.

Substitute d0=(2P0+d1)/3 and collect terms to obtain

4d1+d2 = 6P1-P0.

The last row similarly becomes

d_{N-2}+4d_{N-1} = 6P_{N-1}-PN.

All other rows remain d_{i-1}+4di+d_{i+1}=6Pi. Thus the matrix has
4 on its diagonal and 1 on each adjacent diagonal, as required.
For N=3, substituting into Equation (2) gives exactly

[4 1; 1 4] [d1; d2] = [6P1-P0; 6P2-P3].

For N=2, start from Equation (3): d1=2P1-(d0+d2)/2.
Substitution of both natural boundary formulas gives

4d1=6P1-P0-P2.

This is the same tridiagonal construction with one unknown; both endpoint
corrections must be applied to that single right-hand-side row.
The matrix is strictly diagonally dominant, hence invertible, so the
solution exists uniquely.

## Part 2: Implementation

1. `interpatxy.py` builds the (N-1)-square matrix and solves both coordinate
   systems together using `numpy.linalg.solve(A, rhs)`. It reconstructs
   d_{-1}=P0, d0, the interior points, dN, and d_{N+1}=PN.
   Flat and column inputs are accepted; output coordinate vectors are flat.
2. `bspline2b.py` applies the special end-segment formulas and the interior
   2/3, 1/3 weights. Shared endpoints are midpoints of adjacent Bezier
   handles, ensuring matching first derivatives. These endpoints reproduce
   the supplied data because the de Boor points solve the interpolation system.
   Its parameter N means the last array index, not the PDF's segment count.
3. `drawbezier_dc.py` repeatedly bisects each cubic at t=1/2 using de Casteljau.
   Depth 6 produces 64 line segments per cubic. Control polygons are optional.
4. `get_output.py` exports all six supplied datasets. Each file in part2i
   contains dx,dy; each file in part2ii contains four Bx and four By columns.
   Images show data as blue plus signs and de Boor polygons as dashed red lines.
5. Interactive mode collects two user-selected examples and saves their images
   under part2iii. These examples require actual mouse input and are not
   generated by the noninteractive run.
